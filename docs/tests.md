# Tests

```sh
pixi run test        # mvn -B verify, JDK 25
cd cuda && pixi run test && pixi run gpu-test    # gpu-test needs a GPU host
```

## Suite

- `VectorsTest` checks every spec vector, generated from `vectors.json` by `tools/gen_vectors.py`.
- `StreamsTest` checks stream dumps in `src/test/resources/data`, copied from `tandem-c`.
- `DerivedTest` and `ExponentialTest` check bounded, normal and exponential values against
  `tandem-cuda` fixtures, generated by `tools/gen_derived.cpp`.
- `FillsTest` checks fills against scalar draws at cut offsets. `TandemCudaTest` checks GPU fills.

`VectorsTest` checks every vector of the specification. `StreamsTest` compares long fills,
scalar draws and random access against the reference stream dumps in `src/test/resources/data`,
complex fills included. `DerivedTest`
compares bounded integers and normals with values from the `tandem-cuda` core, bounded fills with
rejections, and the cosine and sine halves of float and double normal pairs and fills, generated
by `tools/gen_derived.cpp` into `Derived.java`. `FillsTest` compares every fill with the same
count of scalar draws at offsets and lengths that cut rows, blocks and chunks, and the block cache
with random access at every chunk length. `GaussianTest` checks that scalar normals, pair calls
and fills give one sequence, and the kept half. `ExponentialTest` checks exponential fills and
scalar draws against the `tandem-c` fixture `cross_exponential.h` bit for bit (generated into
`Derived.java` from the `tandem-cuda` core, whose values it equals), the FNV-1a hash of 1e6 double
and 1e6 float exponentials at five positions, fills cut at block boundaries from an unaligned
start, empty fills, and the moments to fourth order and the Kolmogorov-Smirnov distance of 1e7
samples against Exp(1). `TandemTest` covers child keys, forks, serialization and the
`RandomGenerator` contract. `TandemProviderTest` covers the Commons RNG adaptor.

`TandemCudaTest`, tagged `gpu`, compares the four uniform fills with the CPU fills in values and
final position at chunk lengths 1, 2, 4, 8, 32 and 65536 and at starts and lengths that cut words,
blocks, rows and groups. It compares the bounded fills with the CPU fills at ranges that reject
often, rarely and never, and the normal fills with the CPU fills at every start slot. It checks the
bounded and normal fixtures of `tandem-cuda` (`cross_fill_below.h`, `cross_fill_normal.h`, copied
into the test resources), the stream dumps of the core tests, and the device fills against the
array fills. `NoDriverTest` checks the error without a driver.

## Fixtures

`Vectors.java` is generated from the spec repository's `vectors.json` by `tools/gen_vectors.py`.
The stream dumps in `src/test/resources/data` are byte-identical copies of the dumps in
`tandem-c`. `tools/gen_derived.cpp` generates `Derived.java` from the `tandem-cuda` core.
`cross_fill_below.h` and `cross_fill_normal.h` of `tandem-cuda` are copied into the test
resources.
